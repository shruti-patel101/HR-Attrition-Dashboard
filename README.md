# HR-Attrition-Dashboard
Employee attrition analysis using Power BI
About the Project
This dashboard focuses on employee attrition and helps understand employee turnover across departments, years, and job levels.

Key Insights
Total employee attrition is 226.
The attrition rate is 15.07%.
The average employee tenure is 3.05 years.
The Sales department has the highest displayed attrition rate.
Work-life imbalance is the leading reason shown in the reason-wise chart.

Tools Used
Power BI, DAX, Data Visualization

Conclusion
This dashboard helps identify employee attrition patterns and gives HR teams insights into areas where employee retention can be improved.
